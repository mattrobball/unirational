# Retraction application after the postcomposition correction

The accepted degree-one normal form remains mathematically valid for a
hypothetical ambient map whose restriction is the identity:

\[
T=Hx+FQ,
\qquad
F(x+tQ)=(Ht-F)(St^2-Rt-1),
\qquad
\Delta=R^2+4S.
\]

The nonsquare discriminant branch is still not excluded by the polar identities
alone.

However the logical role of this branch changes. If such a retraction existed,
postcomposition with any nonidentity intrinsic `G`-selfmap `sigma` would give
an ambient landing map whose restriction is `sigma`, hence degree at least 3.
Therefore a theorem asserting that every ambient restriction has degree one is
incompatible with the existence of a retraction.

Accordingly there is no valid architecture

```text
all ambient restrictions degree one
-> identity
-> analyze surviving retraction
```

unless the first step already proves that there are no ambient maps at all.

The retraction identities remain useful only as a special test family inside a
hypothetical nonempty ambient category. Excluding the nonsquare branch would
exclude retractions, but would not exclude ambient maps whose restriction has
higher degree.

The headline negative problem now requires a direct proof of

```text
NO-DOMINANT-G-AMBIENT-LANDING-MAP
```

rather than sequential exclusion of higher-degree maps followed by a surviving
retraction branch.
