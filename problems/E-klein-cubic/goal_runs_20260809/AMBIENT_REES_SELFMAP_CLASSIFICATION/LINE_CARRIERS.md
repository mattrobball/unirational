# Rational line carriers

For an involution `t`, the target fixed line is `L_t=P(W_-(t))`. The parity
calculation along the forced plus-plane base locus shows that any defined odd
first normal layer maps into `L_t`.

Residual `S_3` symmetry alone allows the infinite family

\[
R(z)=zA(z^3),\qquad A(u)A(u^{-1})=1.
\]

Normalized-Rees geometry does not presently reduce this to a finite list. A
canonical line carrier must be a `t`-fixed horizontal curve contained in a
canonical Rees divisor, not an arbitrary curve on a later resolution.

For such a carrier `R`, if its degree over the source fixed line is
`epsilon_L`, the exact polarization identity remains

\[
r=d\epsilon_L-B\cdot R.
\]

Neither `epsilon_L=1` nor `B.R=0` follows from the landing identity. The type-II
product-zero theorem additionally shows that first point-exceptional surfaces
are naturally driven into an edge of the V4 minus-triangle, so rational line
carriers can occur before missing elliptic directions reappear at higher Rees
order.

No finite classification of line-carrier degrees is proved.
