# Noether--Fano after the Rees correction

For a resolved landing map one has

\[
q^*H=d\pi^*H-\sum m_EE,
\qquad
\pi^*X=D+\sum c_EE,
\qquad
K_Z=-5\pi^*H+\sum k_EE.
\]

The pair `(P^4,X)` is plt, giving the standard discrepancy inequality
`k_E-c_E>=0` for exceptional divisors over the source. The landing identity
adds the residue-map condition on each Rees divisor, but no formal inequality
of the shape `lambda m_E+mu c_E<=nu k_E` follows from it alone.

The exact fibre identities

\[
\sum m_Ee_E=da,
\qquad
\delta=3a-\sum c_Ee_E
\]

therefore do not force `delta=1` without a classification of the actual Rees
centers or a new center-sensitive inequality.

More importantly, the postcomposition theorem shows that any universal
argument forcing `delta=1` for every ambient landing restriction would force
the ambient landing set to be empty. Thus any successful Noether--Fano/Rees
inequality is in fact an **existence obstruction**, not a classification
inequality for a nonempty degree-one family.
