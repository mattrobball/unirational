# Polarization and base correction

For any genuine elliptic horizontal carrier `C`, with source degree `epsilon`
and target map `[n]+a`, the accepted identity is

\[
3n^2=3d\epsilon-B\cdot C.
\]

For a rational carrier `R` mapping to `L_t` with degree `r`,

\[
r=d\epsilon_L-B\cdot R.
\]

These formulas remain exact, but the normalized-Rees analysis in this packet
does not determine `epsilon`, `epsilon_L`, or either base intersection.

The first involution-layer parity theorem only determines whether a defined
initial map lands in `E_t` or `L_t`; it does not prove that the relevant Rees
curve is birational over the source fixed curve or disjoint from the residual
base divisor. Likewise the type-II product-zero relation often forces one
character direction to higher order, increasing rather than eliminating the
possibility of base correction.

Therefore neither `n^2=d` nor the old numerical implication `[-5] => d=25` is
valid for an exceptional carrier without additional Rees geometry.

The profile `([-5],id)` remains a valid reduced-network morphism but has no
proved ambient exceptional realization.
