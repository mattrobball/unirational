# Branch and monodromy

Branch/monodromy arguments remain secondary. The accepted intrinsic selfmaps
already show that dominant `G`-selfmaps of degree greater than one can exist,
so monodromy cannot by itself imply rigidity.

For an ambient landing map, a branch computation becomes meaningful only
after the actual normalized-Rees centers are known well enough to calculate
the finite Stein model and ramification divisor. The invariant lower bound
`H^0(X,O_X(m))^G=0` for `1<=m<=4` can then obstruct a branch class only if the
Rees calculation forces it into those small classes.

No such branch-class bound is proved here. Postcomposition also shows that, if
one ambient landing exists, there are ambient restrictions of unbounded degree,
so a branch theorem intended to force all ambient degrees to one would have to
prove emptiness of the ambient landing set.
