# Comparison with the existing degree-25 tower

## 1. What the stored tower parametrizes

The accepted transition and lifting packages start from the theorem that every
landing covariant has every involution plus-plane in its base locus. If \(m\)
is the first nonzero transverse order, then \(m\) is odd and the leading term
is \(E_-(t)\)-valued.

Thus the first nonzero datum is a map on

\[
\mathbf P(N_{Z_t/\mathbf P(W)})
\]

to the target fixed line \(L_t\). It is not a value of the rational map on
\(Z_t\), and it is not a map on \(E_t\subset Z_t\).

The category repair explicitly distinguishes:

1. the source fixed line \(\mathbf P(E_-(t))\);
2. the exceptional normal-direction factor \(\mathbf P(E_-(t))^N\);
3. the target fixed line \(L_t\).

None is the fixed elliptic \(E_t\).

## 2. Degree-25 state

The stored degree-25 packet uses

\[
(m,d)=(1,25)
\]

and records nonempty free-fibre zero loci through the finite normal expansion.
Its own theorem boundary says:

- it is not a covariant;
- it is not a global \(G\)-gluing result;
- it is not a parametrization;
- the surviving state is only necessary formal data.

The leading state is \(E_-\)-valued in normal order one. The proposed
\([-5]\) map is \(E_+\)-valued and nonzero in order zero on \(E_t\). These lie
in different filtration degrees and different involution eigenspaces.

Therefore the surviving formal state is **not**:

- the canonical boundary map;
- a deformation of the canonical boundary map;
- evidence for extension of that map.

It is unrelated except for the numerical source degree \(25\).

## 3. Source-line coefficient data

At \((m,d)=(1,25)\), the repaired source-line condition is either zero or has
the mandatory scalar factor

\[
\Delta_t
\]

of degree six. This coefficient coupling is terminal data on the source fixed
line, not restriction of the normal jet.

A rational identity map on a line would require a radial tuple
\(h_t(y)y\) with \(\deg h_t=24\). Matching that form would still say nothing
about the elliptic value, and the mandatory vanishing at marked points would
have to be canceled rationally. The plus-plane theorem independently forces
zero on every \(E_t\).
