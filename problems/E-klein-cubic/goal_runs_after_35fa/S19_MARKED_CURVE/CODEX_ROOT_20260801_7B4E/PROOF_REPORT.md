Exact substitution verifies on every line

```text

f5(u_i*s+v_i*t) = 0.
```

For a hyperplane `h=(h0,...,h4)`, its intersection with the `i`-th line is

```text
p_i(h) = (h.v_i)u_i - (h.u_i)v_i.
```

The JSON stores every coefficient of these 55 by 5 linear forms in the
integral cyclotomic basis `1,z,...,z^9`.  In ambient `P4`, the ideal of one
section is generated by the hyperplane equation and the ten projective
2-by-2 minors

```text

```

`0 <= a < b <= 3` give the corresponding point ideal in `P3`.  The universal
marked ideal is the intersection of the 55 section ideals.

The serialized `S,T` permutations and exact line-span checks also certify
descent equivariance.  If points transform by `x -> rho(g)x`, hyperplanes

intersection gives

```text

```

Thus the construction uses the full descended orbit, not 55 unrelated
geometric points.



- `s_i*t_j-t_i*s_j != 0` for every pair;

## 3. Smooth marked tangent and obstruction

Suppose an admissible image is a smooth nondegenerate rational curve `C` in
one fixed `P3`, and let `Z` be its 55 marked points.  By Birkhoff--Grothendieck
write

```text
N_C/P3 = O(19+b1) + O(19+b2).
```

The normal degree is `4*19-2=74`, so `b1+b2=36`.  The bundle `N(-1)` is a
quotient of `T_P3(-1)|C` and is globally generated, hence `b_i >= 0`.
Nondegeneracy makes the four coordinate forms linearly independent.  The
Euler sequence then gives `H0(Omega_P3(1)|C)=0`; the conormal injection gives
`H0(N^*(1))=0`, excluding `b_i=0`.  Therefore

```text
1 <= b_i <= 35.
```

Twisting by the 55 reduced points gives

```text
N(-Z) = O(b1-36) + O(b2-36).
```

Both summands have negative degree, so

```text
h0(N(-Z)) = 0,
h1(N(-Z)) = 34.
```

Thus a smooth candidate is isolated in its fixed-hyperplane marked Hilbert
fibre.  In the relative hyperplane family, if `r` is the rank of the map
from the four hyperplane directions to `H1(N(-Z))`, then

```text
relative tangent dimension = 4-r,
relative obstruction dimension = 34-r,
0 <= r <= 4.
```

No candidate exists at which to compute `r`.  This theorem does not cover a
singular rational image.
