# Center audit

## Center used by the exact link

| datum | exact value |
|---|---|
| ambient variety | generic Klein cubic twist \(X/K_0\) |
| center | \(C=X\cap\{a_3=a_4=0\}\) |
| field of definition | \(K_0=\mathbf C(W)^G\) |
| geometric type | smooth plane cubic |
| degree / genus | \((d,g)=(3,1)\) |
| ideal on \(X\) | \((a_3,a_4)\) |
| normal bundle | \(\mathcal O_C(1)\oplus\mathcal O_C(1)\) |
| extraction | ordinary blowup |
| discrepancy | \(1\) |
| singularities after extraction | none; \(Y\) is smooth |
| exceptional divisor | \(E\simeq C\times\mathbf P^1\) |

The last identification uses that both normal summands are the same line
bundle.  Under \(f\), the second factor is the pencil base.  A closed point
of degree \(m\) on \(C\) gives an exceptional multisection of degree \(m\),
not a section unless \(m=1\).

## Standard weak-Fano curve-center census

For a smooth geometrically integral curve of genus \(g\) and degree \(d\)
on a smooth cubic threefold, the ordinary blowup has

\[
(-K)^3=22-4d+2g.
\]

The standard weak-Fano list is:

| \((g,d)\) | second contraction / link behavior | generic-twist status here |
|---|---|---|
| \((0,1)\) | conic bundle | no generic-twist line in the accepted dossier |
| \((0,2)\) | degree-4 del Pezzo fibration | no geometrically integral generic-twist plane conic |
| \((0,3)\) | terminal rank-one Fano | not needed for this structural exit |
| **\((1,3)\)** | **degree-3 del Pezzo fibration** | **constructed exactly here** |
| \((1,4)\) | divisorial anticanonical contraction | no small link |
| \((4,6)\) | divisorial anticanonical contraction | no small link |
| \((0,4)\) | link to a point on a genus-8 degree-14 Fano | accepted headline-positive bridge if the target point exists |
| \((0,5)\) | cubic self-link | not needed here |
| \((1,5)\) | link through an elliptic quintic to a genus-8 Fano | Pfaffian descent remains open |
| \((2,6)\) | cubic self-link | not needed here |

This is a routing census from Blanc--Lamy, not a classification of singular
centers, nonreduced orbit schemes, weighted extractions, or every semilinear
generic-twist center.  Such exhaustiveness would be necessary for a rigidity
exit but is not used for the explicit structural exit.

## Point and orbit boundary

For the blowup of a reduced point of a cubic threefold,
\(-K=2H-2E\) and \((-K)^3=16\).  For a reduced degree-\(n\) point cycle the
same disjoint-geometric-point computation gives \(24-8n\); in particular the
known degree-55 and degree-60 cycles do not give weak-Fano ordinary point
blowups.  This numerical exclusion does not classify weighted extractions.
