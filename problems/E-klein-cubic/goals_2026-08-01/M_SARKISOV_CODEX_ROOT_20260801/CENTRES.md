# Center audit

## The center used by the certified link

| datum | exact value |
|---|---|
| ambient variety | generic Klein cubic twist \(X/K_0\) |
| center | \(C=X\cap\{a_3=a_4=0\}\) |
| field of definition | \(K_0=\mathbf C(W)^G\) |
| geometric type | smooth plane cubic |
| degree / genus | \((d,g)=(3,1)\) |
| ideal on \(X\) | \((a_3,a_4)\) |
| normal bundle | \(\mathcal O_C(1)\oplus\mathcal O_C(1)\) |
| extraction | ordinary blowup |
| discrepancy | \(1\) |
| singularities after extraction | none; \(Y\) is smooth |
| exceptional divisor | \(E\simeq C\times\mathbf P^1\) |

The last identification follows because both normal summands are the same
line bundle, so \(\mathbf P_C(N_{C/X})\simeq C\times\mathbf P^1\).  Under
\(f\), the second factor is the base pencil.  Hence a closed point of degree
\(m\) on \(C\) gives an exceptional multisection of degree \(m\).  An
exceptional section exists exactly when \(C(K_0)\ne\varnothing\); no
degree-one conclusion is inferred from higher-degree closed points.

## Classical weak-Fano curve-center census

For orientation, the smooth geometrically integral curve blowups of a smooth
cubic threefold that occur in the standard weak-Fano classification have the
following numerical types.  The table is used only as a routing census; the
certified link uses the highlighted \((1,3)\) row.

| \((g,d)\) | standard second contraction / link behavior | generic-twist status here |
|---|---|---|
| \((0,1)\) | conic bundle | excluded as a \(K_0\)-defined line by the accepted Problem E dossier |
| \((0,2)\) | degree-4 del Pezzo fibration | excluded as a \(K_0\)-defined conic by the accepted Problem E dossier |
| \((0,3)\) | terminal Fano target | not needed for the structural exit |
| **\((1,3)\)** | **degree-3 del Pezzo fibration** | **constructed and verified here** |
| \((1,4)\) | divisorial anticanonical contraction | not needed here |
| \((4,6)\) | divisorial anticanonical contraction | not needed here |
| \((0,4)\) | link to a point on a genus-8 degree-14 Fano threefold | not needed here |
| \((0,5)\) | link to another cubic threefold | not needed here |
| \((1,5)\) | link through an elliptic quintic to a genus-8 degree-14 Fano | Pfaffian/descent obstruction remains as in the parent dossier |
| \((2,6)\) | link to another cubic threefold | not needed here |

This table does not classify singular centers, nonreduced orbit schemes,
weighted extractions, or all higher-rank equivariant models.  Such an
exhaustive audit would be required for a rigidity exit; it is not required to
certify the explicit new-Mori-fibre exit proved here.

## Orbit-center boundary

The familiar split \(G\)-orbits, fixed elliptic curves of small subgroups, and
the \(A_4/D_{12}\) orbit schemes are not silently promoted to
\(K_0\)-defined centers on the generic twist.  Descent requires a stable
scheme with its actual residue algebra, not just a geometric orbit after
base change.  No headline conclusion in this packet depends on those
unverified descents.
