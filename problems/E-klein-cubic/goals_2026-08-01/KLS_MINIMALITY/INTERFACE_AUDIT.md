# KLS interface audit

## 1. Two different notions must not be conflated

Let `q:W -> W` be a nonzero primitive homogeneous `G`-self-covariant.

- A **KLS rank-drop covariant** satisfies `det(Dq)=0`.  The exact
  covariant-dimension lower bound forces its affine image to have dimension
  four, hence its projective image is an irreducible invariant unirational
  hypersurface `H=V(F)` in `P(W)`.  This hypersurface need not be the Klein
  cubic.
- A **Klein-landing covariant** additionally satisfies `f3(q)=0`.  If its
  generic differential has rank four, its projective image is a
  three-dimensional irreducible subvariety of the threefold `X=V(f3)`, so it
  equals `X`.

For a Klein-landing covariant, set

```text
h = gcd_i (partial_i f3)(q).
```

Then `h=1`.  Indeed, if a prime `g` divided all five pulled-back partials,
primitivity says the generic value of `[q]` along `V(g)` is defined.  It would
be a projective common zero of the five partial derivatives of `f3`, hence a
singular point of the smooth Klein cubic.  This is impossible.  Equivalently,
the global image theorem gives `h=1` and `r+t=2d-4` in the Klein branch.

Therefore the normalization of the projective image is just the smooth Klein
cubic and its conductor divisor is zero.  The degree-22 factor `P22` is not a
possible conductor support for a genuine landing map.  `P22` belongs to the
separate singular-image KLS reduction whose missing purpose is to prove that a
minimal KLS image must be the Klein cubic.

## 2. Exact KLS objects

For a general rank-four KLS covariant with image `H=V(F)`, put

```text
A_i = (partial_i F)(q)
h   = gcd(A_0,...,A_4)
Abar = (A_0,...,A_4)/h.
```

Let `v` be the primitive right-kernel row of `Dq` and write

```text
adj(Dq) = b v Abar^t.
```

With

```text
d = deg(q), e = deg(H), s = deg(h),
r = deg(v), t = deg(b),
```

the exact global identity is

```text
s = r + t + d(e-5) + 4.                         (I)
```

The divisor `V(h)` is precisely the divisorial part of the inverse image of
`Sing(H)`.  Every factor of `h` is a Darboux leaf divisor for the rank-one
foliation generated by `v`.

The normalized dual Gauss covariant

```text
p = (grad F)(q)/h : W -> W*
```

is primitive of rank four and degree

```text
m = d(e-1)-s = 4d-4-r-t.                         (II)
```

Since `W*` is not isomorphic to `W`, minimality does not apply directly.
Composing with the quadratic dual Klein polar returns to `W` with degree
`2m`, yielding only

```text
d <= 2m,
r+t <= floor((7d-8)/2).                           (III)
```

## 3. Normalization and conductor ledger

Let `nu:Y=H^nu -> H` be the normalization and let `C` be its conductor
divisor, so

```text
K_Y + C = nu^* K_H.
```

For a source prime `D=V(g)` dividing `h`, suppose

```text
ord_D|K(Y) = epsilon_D ord_E.
```

If `a_D=ord_D(h)` and `beta_D=ord_D(b)`, the accepted exact identity is

```text
beta_D - a_D = epsilon_D A_E(Y,C) - 1.             (IV)
```

When `D` dominates a conductor prime `T`, with conductor coefficient `c_T`
and normalization-differential order `mu_T`, this specializes to

```text
a_D    = epsilon_D(c_T+mu_T),
beta_D = (epsilon_D-1)+epsilon_D mu_T,
a_D-beta_D = 1+epsilon_D(c_T-1).                   (V)
```

Thus a squarefree conductor factor is necessarily an immersed transverse
ordinary-node branch.  For a codimension-at-least-two center, squarefree
support cancels from `s-t`, while a repeated factor cancels fully only when
`A_E(Y,C)>=1`.

## 4. The factor `P22`

For either maximal `A5<G`, the restricted representation has a unique
nondegenerate invariant quadric.  The eleven translates are distinct, and
their squarefree product is the degree-22 invariant `P22`.

Proved scope:

- If `H` is normal, no one of these quadrics divides `h`; hence `P22` does
  not divide `h`.
- If `H` is nonnormal and the eleven factors are exactly the
  conductor-dominating support, literal `h=P22` is excluded through the
  complete degree-nine KLS certificates.
- The same exclusion holds for `h=P22*k` when `k` is coprime and squarefree,
  centered in codimension at least two, and contributes no further
  conductor-dominating support.  Arbitrary multiplicities of `k` are also
  covered if all relevant discrepancies are at least one.
- The degree-25 and degree-28 logarithmic fields show that equivariance,
  primitivity, and tangency to `P22` are not a rigidity theorem.  They are
  not KLS Jacobian kernels.
- An exact dominant `A5`-equivariant map from the invariant quadric to
  `P2` shows that a divisorial conductor-surface image is
  representation-theoretically feasible.  It does not construct a KLS map.

## 5. Quartic precomposition

The primitive quartic covariant `C:W->W` defines a finite surjective
endomorphism of `P(W)` of degree `256`.  If `q` is primitive, rank four, and
KLS, then

```text
q o C^n
```

is primitive, has the same image and generic rank, and has saturated degree
`4^n d`.  Hence precomposition cannot contradict the minimality of `q`.
The only valid descent statement is that a *pure* pullback `q=q0 o C` would
contradict minimality.  A general `C`-adic expansion has 1,024 residue terms,
and derivations mix them across the degree-15 ramification divisor; no
coefficientwise KLS descent is proved.

## 7. Source-exhaustiveness bridge

The valid negative bridge would be

```text
no rank-four KLS self-covariant
  => covdim(G)=5
  => ed_C(G)=4
  => the Klein cubic is not G-unirational.
```

The first implication required by this route is not established because the
singular/noncanonical image branch is open.  Eliminating only `P22` support,
or only landing covariants, does not exhaust rank-four KLS covariants.
