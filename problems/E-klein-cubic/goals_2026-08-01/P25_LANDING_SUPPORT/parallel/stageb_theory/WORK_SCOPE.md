# Stage-B theory work scope

This directory contains an independent exact audit of structural shortcuts for
Stage B.  Immutable inputs outside this directory are read but never modified.

The target is the projective rank-drop locus of the sealed mixed-degree matrix
`[M1(q) | M2(q)]`.  Exact reformulations and replayable finite-field identities
are recorded here.  Coordinate checks, random-point checks, expected
codimension, vanishing Porteous classes, and incomplete module computations are
all treated as nonverdicts.
