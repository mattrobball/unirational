# Work scope

This directory audits only the faithful polarized Stage-B map

```text
L(q) : F_89^243 -> F_89^690.
```

It studies the equivalent intersection of `P(ker(flatten(L)))` with the
Segre variety `P^36 x P^242`, computes exact multigraded Macaulay dimension
floors, and records bounded low-degree rank information.  It does not modify
sealed inputs or run a projective saturation.
