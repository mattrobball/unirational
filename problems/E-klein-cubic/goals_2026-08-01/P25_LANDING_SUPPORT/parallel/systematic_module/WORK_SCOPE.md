# Systematic-module work scope

This directory contains exact experiments built from the sealed 690-row lower
presentation over `F_89`.  It has two deliberately separate tracks:

1. a single affine Stage-B chart `q0=1, b1_0=1`, using all 690 original
   equations `M1(q)b1+M2(q)b2=0`; and
2. weighted-module jobs which exploit the systematic coefficient flattening
   of `M2`.

An empty affine chart is only a chartwise result.  It does not cover the other
`q` or `b1` flags.  A timeout, resource kill, incomplete output, or nonunit
Groebner basis is a nonverdict.
