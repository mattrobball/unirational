# Status

`SCHUR-CONIC-ALL-DEGREES-REDUCED-TO-DEGREE4`

The Pfaffian kernel fibre of any point on the genuine generic Klein twist
extends to a morphism from the Schur conic to the twisted \(V_{14}\).  A
rational point on the smooth cubic can be chosen so that its kernel conic
avoids the flop locus.  The pulled-back tautological bundle then splits
geometrically as \(\mathcal O(-1)\oplus\mathcal O(-3)\), so the Plücker
degree is exactly four.  The same splitting rules out a multiple cover,
so the image is a geometrically integral quartic normalized by the Schur
conic.

Headline status: **OPEN**.  The remaining quartic-existence question is
equivalent to the original point problem.
