### scheme

**Certificate naming convention observed:**

1. **Directory prefixes** group attempts by major strategy:
   - `degree25_*` → P (degree 25 coefficient model): exact, direct_support, finite_module, global, p25v, p25w, rank_k, rowrank, support_f4, tower, molien
   - `fold_*` → T (fold algebra): normalization, normalization_t2r, normalization_t3, decision_t6, decision_t8, decision_t8n1, binodal_t9, t11, t11b
   - `fano_*` → C (Fano surface): interface_c0, c1, c2, c2_1, c3
   - `global_*` → GLIFT (global lifting): lifting, finite_lifting, lifting_decision, terminal_module, transition
   - `schur_*` → A (Schur-Krylov): krylov, degree19
   - `target_branch_*` → B (target branch): global, mod3, t10
   - Others → SUPPORT or AUD (supporting computations)

2. **Exit status files** (`exit*.json`, `exit.json`): JSON containing `"exit"` (status label) and `"headline"` (OPEN/other) fields. Variants include exit_p25x0, exit_p25x1, exit_p25y, exit_p25z1, exit_p25r0, exit_p25r1, exit_p25r2, exit_p25v0, exit_p25v1, exit_p25w0, exit_p25w1, exit_p25w3, exit_c0, exit_c1, exit_c2, exit_c21, exit_c3, exit_t8n1, exit_t9, exit_t11, exit_t11b, exit_t10, exit.

3. **Seal files** (`SEAL.json`): JSON metadata recording artifact SHA256 hashes, gate statuses, headline status, bottlenecks, not_proved flags; serves as integrity seal for portable subsets.

4. **Documentation** (`*.md`): Strategy and result documents (COEFFICIENT_MODEL, FINITE_PRESENTATION, LANDING_IDEAL, SERRE_NORMALITY, PICARD_OBSTRUCTION, DVR_MODEL, SUPPORT_P25YB, MOLIEN_BOUND, ROW_RANK, RANK_K, TOWER, FINITE_BIRATIONAL, FACTORWISE_SATURATION, R1_DECISION, SUBRESULTANT_AUDIT, BINODAL_COMPONENT, HENSEL_NONUNIT, EXACT_LOCAL_CHART, MODULAR_SIMPLE_POINT, ROUTE_C, FULL_FINITE_TOWER, GLOBAL_CORRECTION_SPACES, etc.)

5. **Data files** (`.json`, `.npz`, `.out`, `.py`): Matrices, bases, mappings, verification scripts, msolve outputs; support reproducibility and portability.

Each directory represents a scoped exclusion or necessary-condition computation toward the headline PSL(2,11)-equivariant unirationality question. All directories retain a portable Git-publishable subset with SHA256 seals.
