## 1. The two Ext estimates

Let `M = IC_{S̄}^H(L)` be a proper strict-support constituent of
`{}^pH^j(R p_* IC_Y^H)`, `s = dim S ≤ 2`, and ask when the component map

```
M[-j]  --->  i_* IC_X^H [1]
```

of (4.1) can be nonzero.

**Lemma 1.1 (degree window).** `M[-j]` contributes
`IH^{s-1-j}(S̄, L)` to `IH^3(Y)`, so a nonzero contribution needs

```
j <= s - 1.                                                        (1.1)
```

*Proof.* `IH^3(Y) = H^{-1}(P^4, R p_* IC_Y)`, and `M[-j]` contributes
`H^{-1-j}(P^4, M) = H^{-1-j}(S̄, IC_{S̄}(L)) = IH^{s-1-j}(S̄,L)`. Nonvanishing
forces `0 ≤ s-1-j ≤ 2s`, in particular `j ≤ s-1`. ∎

**Lemma 1.2 (codimension Ext vanishing).** For `N` perverse on the smooth
threefold `X`, supported in codimension `c`, `Ext^a(N, IC_X) = 0` for `a < c`.

*Proof.* `N = k_* N''` for `k : Z ↪ X` of codimension `c`;
`Hom(k_*N'', IC_X[a]) = Hom(N'', k^! IC_X[a])` and `k^!IC_X ∈ {}^pD^{≥c}`, so
`k^!IC_X[a] ∈ {}^pD^{≥ c-a}`, which admits no nonzero map from the perverse
`N''` when `c - a > 0`. ∎

**Lemma 1.3 (`S` not inside `X`).** If `S ⊄ X` then a nonzero component map
forces `j ≥ 4 - s`.

*Proof.* By adjunction `Hom(M[-j], i_*IC_X[1]) = Hom(i^*M, IC_X[1+j])`. For the
Cartier divisor `i : X ↪ P^4`, `i^*M` has perverse amplitude `[-1,0]`. The
triangle `{}^pH^{-1}(i^*M)[1] → i^*M → {}^pH^0(i^*M)` gives: a nonzero map needs

```
Ext^{1+j}( {}^pH^0(i^*M), IC_X ) != 0    or    Ext^{j}( {}^pH^{-1}(i^*M), IC_X ) != 0.
```

Now `{}^pH^{-1}(i^*M)` is the transverse part, supported on `S̄ ∩ X` of dimension
`≤ s-1`, so of codimension `c_{-1} ≥ 4-s` in `X`; and `{}^pH^0(i^*M)` is the
non-transverse part, supported in dimension `≤ s-2`, so `c_0 ≥ 5-s`. Lemma 1.2
gives `j ≥ c_{-1} ≥ 4-s` in the first case and `1+j ≥ c_0 ≥ 5-s`, i.e.
`j ≥ 4-s`, in the second. Both branches give `j ≥ 4-s`. ∎

> **Adjudication note (an error we did not find).** The external source's
> inequality `(2.5)`, `j ≥ 4-s`, is correct. On a first pass we mis-indexed the
> `{}^pH^{-1}` branch as `Ext^{j+2}` and concluded that only `j ≥ 2-s` followed,
> which would have left `s = 2, S ⊄ X` alive. The correct identity is
> `Hom(A[1], B[1+j]) = Ext^{j}(A,B)`; both branches then give `j ≥ 4-s`. The
> external inequality stands. Recorded because it is the one place where the
> external bookkeeping is tighter than a careless reading suggests.

**Lemma 1.4 (`S` inside `X`).** If `S ⊂ X` then `i^*M = M'` where
`M' = IC_{S̄}^H(L)` regarded on `X` (because `i^* i_* = id` for a closed
immersion), of codimension `c = 3 - s`, and a nonzero map forces
`1 + j ≥ 3 - s`, i.e. `j ≥ 2 - s`.

**Theorem 1.5 (support classification).** A proper ambient strict support can
map nontrivially to the restricted full-support summand only if

```
S subset X   and   dim S = 2.
```

*Proof.* If `S ⊄ X`: `(1.1)` and Lemma 1.3 need `4-s ≤ s-1`, i.e. `s ≥ 2.5`,
impossible for `s ≤ 2`. If `S ⊂ X`: `(1.1)` and Lemma 1.4 need `2-s ≤ s-1`,
i.e. `s ≥ 1.5`, so `s = 2`. ∎

**Corollary 1.6 (`S` is a component of `D_X`).** Every proper ambient strict
support lies in the base locus of `A`
(`AMBIENT_HODGE_REES_BRIDGE/THEOREM.md`, Theorem B), so all five coordinates of
`A` vanish along `S`. `S` is a prime divisor on `X`, and `X` is factorial
(smooth, `Pic X = Z·H`), so the local equation of `S` divides every restricted
coordinate `A_i|_X`, hence divides their gcd. Therefore `S` is an irreducible
component of `D_X`. ∎

## 2. Perverse degree and the local system

**Lemma 2.1 (`j = 0`).** For a surface support `S ⊂ X ⊂ P^4` (codimension 2 in
`P^4`), the generic fibre of `p : Y → P^4` over `S` is one-dimensional: at the
generic point of `S` the normalized blowup of `I_A` is the normalized blowup of
an `m`-primary ideal on a two-dimensional regular slice. The standard
fibre-dimension bound for the decomposition theorem gives constituents with
support `S̄` only in perverse degrees `|j| ≤ 2d - codim = 2·1 - 2 = 0`. Hence
`j = 0`; the map is semismall along `S`.

**Lemma 2.2 (the block).** The `S`-supported block is
`IC_S^H(U)(-1)`, where `U` is the local system on a dense open `S°` generated by
the fundamental classes of the exceptional curve components over the generic
point of `S`. Its monodromy permutes those components, hence is finite; the
Tate twist `(-1)` is the curve-class twist. Its contribution to `IH^3(Y)(1)` is
`IH^1(S̄, U)`.

**Theorem 2.3.** Combining: leakage is possible only through

```
S subset D_X,   dim S = 2,   j = 0,   block IC_S^H(U)(-1),   carrier IH^1(S,U).
```

**Theorem 2.4** is Theorem 1.5 + Corollary 1.6 + Lemmas 2.1–2.2, the form used
in `THEOREM_ACTUAL_TRANSFER.md` section 4.

Exit `LEAKAGE-SUPPORT-CLASSIFICATION-PROVED`.

## 3. The finite-monodromy escape collapses to constant coefficients

**Theorem 3.1 (constant-quotient collapse).** Let `a : S ↪ X` be an irreducible
reduced Cartier surface, `S°` a dense open where `S` is smooth and `U` is lisse,
`Z = S \ S°` (so `codim_X Z ≥ 2`). Then restriction induces an isomorphism

```
Hom_{D^b MHM(X)} ( a_* IC_S^H(U)(-1),  IC_X^H[1] )
     ~=   Hom_{VHS(S°)} ( U, Q ).                                   (3.1)
```

*Proof.* Three steps; all three are re-derived here.

**(i) The twist matches.** For the smooth locus, `a^! Q_X = Q_S(-1)[-2]`, hence
`a^! IC_X[1] = Q_S(-1)[3-2+1] = Q_S(-1)[2] = IC_S(-1)`. Adjunction gives

```
Hom(a_* IC_S(U)(-1), IC_X[1]) = Hom(IC_S(U)(-1), IC_S(-1)) = Hom(IC_S(U), IC_S)
                              = Hom_{VHS}(U, Q),
```
the last step because morphisms between Hodge modules with strict support `S`
are morphisms of the generic variations. The `(-1)` on the left cancels the
`(-1)` produced by `a^!`: the external source's twist in its block `(7)` is
exactly right, and this is a nontrivial consistency check on the whole set-up.

**(ii) Existence of the singular Cartier Gysin map.** For general (singular) `S`
the map `gamma_S : a_* IC_S(-1) → IC_X[1]` is *not* immediate from a fundamental
class, because the natural map goes `Q_S[2] → IC_S`, the wrong way. It does
exist, via a resolution: let `f : S̃ → S → X` with `S̃` smooth projective of
dimension 2. Then `f^! Q_X = Q_{S̃}(-1)[-2]`, and the counit `f_! f^! → id`
gives `f_* Q_{S̃}(-1)[2] → Q_X[4] = IC_X[1]`. By the decomposition theorem
`IC_S` is a direct summand of `R f_* Q_{S̃}[2]`, so
`a_* IC_S(-1) ↪ R f_* Q_{S̃}(-1)[2] → IC_X[1]`. Composing with the intermediate
extension of any `l : U → Q` realizes every element of the right-hand side of
(3.1).

**(iii) Injectivity of restriction to `S°`.** Let `phi : A → IC_X[1]` vanish on
`X \ Z`, where `A = a_*IC_S(U)(-1)` is perverse. From the triangle
`j_! j^* A → A → k_* k^* A` (`k : Z ↪ X`), `phi` factors through `k_*k^*A`. Now
`A` is perverse, so `A ∈ {}^pD^{≥0}`, while `k_*k^*A ∈ {}^pD^{≤0}`; hence

```
Hom(A, k_* k^* A) = Hom(A, {}^pH^0(k_* k^* A)),
```
i.e. the factorization passes through the *perverse* sheaf
`N_0 = {}^pH^0(k_*k^*A)`, supported on `Z` of codimension `≥ 2`. Then
`phi ∈ image of Hom(N_0, IC_X[1]) = Ext^1(N_0, IC_X) = 0` by Lemma 1.2 with
`c ≥ 2 > 1`. So `phi = 0`. Over `X \ Z` the situation is the smooth one of (i),
giving `Hom_{VHS(S°)}(U,Q)`. ∎

> **Adjudication note.** The external source's uniqueness argument — "only
> `Ext^0` and `Ext^1` from objects supported in codimension at least two; both
> vanish" — is *correct*, and the reason it is correct is step (iii): because
> `A` is perverse, only the top perverse piece of `k_*k^*A` can receive a map,
> so the higher `Ext`'s that a naive count would allow never arise. The source
> did not say this; we supply it. Verdict: **CONFIRMED with supplied proof.**

**Corollary 3.2.** Every full-support leakage factors as

```
IH^1(S, U)  --->  IH^1(S, Q)  --Gys_S-->  H^3(X)(1) = V.            (3.2)
```

Only the **constant quotient** of `U` can leak: a nontrivial monodromy or Prym
summand cannot by itself produce CLEAN. Exit
`CONSTANT-QUOTIENT-COLLAPSE-PROVED`.

## 4. What CLEAN requires of the surface — and the refutation of "normal suffices"

### 4.1 `H^1(S, O_S) = 0` — CONFIRMED

**Lemma 4.1.** Let `S ⊂ X` be an irreducible reduced surface in a smooth cubic
threefold. Then `S` is Cartier, `S ∈ |aH|` with `a ≥ 1`, and

```
H^1(S, O_S) = 0.
```

*Proof.* `X` is a smooth hypersurface, so `Pic X = Z·H` (Lefschetz) and `S` is
Cartier. `X` is arithmetically Cohen–Macaulay (a hypersurface), so
`H^1(X, O_X(t)) = H^2(X, O_X(t)) = 0` for all `t ∈ Z`. The divisor sequence
`0 → O_X(-a) → O_X → O_S → 0` gives
`0 = H^1(X,O_X) → H^1(S,O_S) → H^2(X,O_X(-a)) = 0`. ∎

### 4.2 `IH^1(S) = H^1(S̃)` — CONFIRMED

**Lemma 4.2.** Let `nu : S^nu → S` be the normalization and `f : S̃ → S^nu` a
resolution. Then `IH^1(S,Q) = IH^1(S^nu,Q) = H^1(S̃,Q)`.

*Proof.* `nu` is finite and an isomorphism over the normal locus, so
`nu_* IC_{S^nu} = IC_S` and intersection cohomology is unchanged. For the
resolution of a normal surface the fibres are curves over points, so the defect
of semismallness is `2·1 - 2 = 0` and
`R f_* Q_{S̃}[2] = IC_{S^nu} ⊕ (skyscrapers in perverse degree 0)`. Skyscrapers
in perverse degree `0` contribute to `H^k(S̃)` only for `k = 2`. Hence
`H^1(S̃) = IH^1(S^nu)`. ∎

### 4.3 The refutation: `S` normal does **not** force `IH^1(S) = 0`

The external message `[20]` section 2, equation `(3)`, asserts

> `S` normal `⟹ IH^1(S,Q) = 0`,

on the ground that "when `S` is normal, intersection cohomology agrees with
ordinary cohomology in degree one", so that `H^1(S,O_S)=0` and conjugation
finish it.

**This is false, and the reason is structural.** For `S` normal the natural map
is only an *injection* `H^1(S,Q) ↪ IH^1(S,Q)`: from the triangle
`Q_S[2] → IC_S → C` with `C` a skyscraper concentrated in degree `-1` with stalk
`H^1(link)`, one gets

```
0 -> H^1(S) -> IH^1(S) -> ⊕_p H^1(link_p) -> H^2(S).
```

`IH^1(S)` is computed on the **resolution** (Lemma 4.2), and `H^1(S,O_S) = 0`
only gives `H^1(S̃, O_{S̃}) ↪ H^0(R^1 f_* O_{S̃})` — which is nonzero exactly
when the singularity is **not rational**.

**Countermodel (exact, machine-verified).** Let

```
X'  =  { x0^3 + x1^3 + x2^3 + x3^2 x4 + x4^3 = 0 }  subset P^4.
```

`verify_normal_surface_countermodel.py` (Part A) and
`cone_surface_countermodel.m2` verify, exactly:

* `X'` is a **smooth** cubic threefold (`Sing(X') = ideal 1` in Macaulay2);
* the hyperplane section `S = X' ∩ {x4 = 0} = {y0^3+y1^3+y2^3 = 0} ⊂ P^3` is the
  projective **cone** over the Fermat plane cubic, with vertex `[0:0:0:1]`;
* the Fermat plane cubic is smooth, hence a genus-1 curve `E`, and projectively
  normal, so `S` is **normal**, irreducible, reduced, and Cartier (`S ∈ |H|`);
* `Sing(S)` is exactly the vertex.

For this `S`, `S̃ = P(O_E ⊕ L)` and

```
IH^1(S,Q) = H^1(S̃,Q) = H^1(E,Q) = Q^2  !=  0,      while  H^1(S,O_S) = 0.
```

(The singularity is simple elliptic; `H^1(S̃,O_{S̃}) = H^1(E,O_E) = C`, and
`H^2(S,O_S) = H^3(X',O_{X'}(-1))^v = H^0(O_{X'}(-1))^v = 0` so the Leray map is
an isomorphism.)

So `(3)` is **REFUTED**: exit `NORMAL-SURFACE-IH1-VANISHING-REFUTED`.

### 4.4 What survives: the `[15]` form of the statement

The correct statement is the weaker one already present in external message
`[15]` section 4, and we confirm it:

**Theorem 4.3.** Let `S` be a common-factor surface component. If `S` is smooth,
or `S` is normal with **rational** singularities, then `IH^1(S,Q) = 0` and `S`
cannot leak.

*Proof.* `S` smooth: `IH^1(S) = H^1(S)`, `H^{0,1} = H^1(S,O_S) = 0` by
Lemma 4.1, and `H^1(S,Q)⊗C = H^{1,0} ⊕ H^{0,1}` with conjugate summands, so
`H^1(S,Q) = 0`. `S` normal with rational singularities: `f_*O_{S̃} = O_S` and
`R^1 f_* O_{S̃} = 0`, so `H^1(S̃,O_{S̃}) = H^1(S,O_S) = 0` by Lemma 4.1, hence
`H^1(S̃,Q) = 0 = IH^1(S,Q)` by Lemma 4.2. ∎

**Corollary 4.4 (CLEAN needs a genuinely singular receiver).** If the restricted
graph is CLEAN, then some irreducible component `S ⊂ D_X` is **not** smooth and
**not** normal-with-rational-singularities: either `S` is nonnormal (and the
irregularity of `S^nu` is forced into the conductor quotient, via
`0 → O_S → nu_*O_{S^nu} → Q_cond → 0` and Lemma 4.1, giving
`H^1(S^nu,O) ↪ H^1(Q_cond)`), or `S` is normal with a **non-rational**
singularity. Exit `CLEAN-IMPLIES-NON-RATIONAL-SINGULAR-RECEIVER-PROVED`.

This is strictly weaker than the external `[20]` conclusion
("surface leakage ⟹ nonnormal"), which is not available.

### 4.5 The Klein cubic has no Eckardt points

The `|H|` witness of section 4.3 is a hyperplane section that is a cone, i.e. it
requires an **Eckardt point**. `eckardt_klein.m2` computes the Eckardt locus of
the Klein cubic exactly — `p` is Eckardt iff the quadratic form
`v ↦ 3Φ(p,v,v) = (1/2) v^T Hess F(p) v` is divisible by the linear form
`v ↦ grad F(p)·v` — and returns

```
Eckardt ideal on the Klein cubic:  ideal 1        (i.e. EMPTY)
```

So **no** hyperplane section of the Klein cubic is a cone over a plane cubic.
Exit `KLEIN-CUBIC-NO-ECKARDT-POINTS`.

*Honest consequence.* Section 4.3 refutes the external claim as a general
statement about Cartier surfaces in smooth cubic threefolds, and therefore
invalidates the argument, which used no Klein-specific input. Whether the Klein
cubic itself contains a normal surface in some `|kH|` with `IH^1 ≠ 0` is
**UNDECIDED** here. Note that for `k ≥ 2` the Leray obstruction group
`H^2(S,O_S) ≅ H^0(X,O_X(k-2))^v` is nonzero, so the `k = 1` computation does not
extend by itself.

## 5. The `G`-structure of a CLEAN receiver

**Lemma 5.1 (component stability).** `D_X ∈ |kH|` is `G`-invariant with
`k ∈ {0} ∪ {5,6,7,...}` (sealed:
`goal_runs_20260810/COMBINED_DEGREE_SIEVE/THEOREM_COMBINED_SIEVE.md`, Lemma 2.3,
exit `COMMON-FACTOR-INVARIANT-DEGREE-SET-PROVED`). If `5 ≤ k ≤ 10`, then every
irreducible component of `D_X` is **individually `G`-stable**.

*Proof.* `G = PSL_2(F_11)` has smallest nontrivial permutation degree `11`: the
minimal index of a proper subgroup is `11` (two classes of `A_5` of index `11`);
the repository records the orbit-size list `11, 11, 12, 55, 66, ..., 660` in
`goal_runs_20260810/RT_SPLIT_AND_DICHOTOMY/DEGREE_ACCOUNTING.md` section 2. `G`
permutes the irreducible components of `D_X`. A component not fixed by `G` lies
in an orbit of size `≥ 11`; each component is a divisor of class `≥ 1·H`, so
that orbit already contributes `≥ 11` to `k`. Since `k ≤ 10`, no such orbit
exists. ∎

