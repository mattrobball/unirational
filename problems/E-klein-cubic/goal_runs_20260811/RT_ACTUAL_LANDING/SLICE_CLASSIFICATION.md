## 0. Setting and notation

`R` is the completed local ring of `P^4` at the generic point `eta_S` of an
irreducible surface `S ⊂ X ⊂ P^4`; it is a **two-dimensional regular local
ring** with residue field `K = kappa(eta_S)` (a field of characteristic zero,
**not** assumed algebraically closed). `f ∈ m_R` is the local equation of `X`,
so `R/(f) = O_{X,eta_S}` is a DVR (X smooth). `A = H B + f C` is the slice of a
landing tuple, `B` and `C` being `5`-tuples in `R` and `B` primitive at
`eta_S` (some `B_i` a unit — after reindexing, `B_0`).

`F` is the Klein cubic form, `Phi` its symmetric trilinear polarization with
`Phi(x,x,x) = F(x)`, so `F(B + t C) = F(B) + 3Phi(B,B,C) t + 3Phi(B,C,C) t^2 +
F(C) t^3` (`verify_slice_universality.py`, `S0a`–`S0d`). The landing-identity
system of `BOXED_GLOBAL_COVARIANT.md` Theorem 1.1 is

```
(I0)   F(B)                          =  f R_0
(I1)   H R_0 + 3 Phi(B,B,C)          =  f R_1                          (10)
(I2)   H R_1 + 3 Phi(B,C,C) + f R_3  =  0
(I3)   F(C)                          =  H R_3 .
```

`I = (A_0, ..., A_4) ⊂ R` is the **slice ideal**.

## 1. The local normal form: `I = (a, f J)` with `J` the Plücker ideal

**Theorem 1.1.** Put `c = C_0/B_0`, `a = H + f c`, and
`d_i = C_i - (B_i/B_0) C_0` for `i = 1,...,4`. Then

```
I  =  (a,  f d_1, ..., f d_4)  =  (a, f J),                             (1)
J  =  ( (B_0 C_i - B_i C_0)/B_0  :  1 <= i <= 4 ).                      (2)
```

`J` is the full local **collinearity (Plücker) ideal** of the pair `(B, C)`,
i.e. it is generated by *all* `2x2` minors `M_{ij} = B_i C_j - B_j C_i`. Both
`A` and `J` are invariant under the gauge change

```
(H, C)  |-->  (H + f U,  C - U B),      U ∈ R,                          (G)
```

and modulo `f`,

```
I / (f)  =  (H)   in   R/(f).                                           (3)
```

*Proof.* `A_0 = H B_0 + f C_0 = B_0 (H + f C_0/B_0) = B_0 a`, and `B_0` is a
unit, so `(A_0) = (a)`. For `i >= 1`,

```
B_0 A_i - B_i A_0  =  f (B_0 C_i - B_i C_0),                            (1.1)
```

an identity verified symbolically (`S1a`); dividing by the unit `B_0` gives
`A_i - (B_i/B_0) A_0 = f d_i`, which is the row operation producing (1). For
(2): the Plücker relation

```
B_0 M_{ij}  =  B_i M_{0j} - B_j M_{0i}                                  (1.2)
```

(`S1c`) together with `B_0` a unit shows `M_{ij} ∈ (M_{01},...,M_{04})` for all
`i,j`, so the four listed generators already generate every minor. Gauge
invariance: `(H + fU)B + f(C - UB) = HB + fC = A` (`S1d`), and
`B_i (C_j - U B_j) - B_j (C_i - U B_i) = M_{ij}` (`S1e`). For (3):
`A_i ≡ H B_i mod f` and `B` is primitive, so the image of `I` in `R/(f)` is
`H · R = (H)` (`S1f`). ∎

**Corollary 1.2 (the two first-order cells).**

* `J = R` (i.e. `B(eta_S)` and `C(eta_S)` are independent over `kappa(eta_S)`):
  then `I = (a, f)`, and since `a ≡ H mod f` while `R/(f)` is a DVR with
  uniformizer `t`, `I = (f, t^m)` with `m = ord_{R/(f)}(H)`. This is the
  **line-type cell**: the surviving exceptional curve maps to a line
  (`BOXED_GLOBAL_COVARIANT.md` section 2.2, row 1).
* `J ⊂ m`: `C(eta_S)` is proportional to `B(eta_S)` and, after a gauge change
  killing the scalar part of `C`, all nonconstant geometry begins in **higher
  jets**. There is no uniform bound on the order of the first noncollinear jet
  (section 5 below).

Exit `SLICE-PLUCKER-NORMAL-FORM-PROVED`.

> **Reading.** Theorem 1.1 is an identity, not a hypothesis: it says the slice
> ideal is *always* the sum of a principal "`H`-direction" part and `f` times a
> collinearity ideal, and the collinearity ideal is the gauge-invariant datum.
> That is what makes the higher-jet cell a genuine cell rather than a
> pathology — nothing in `(10)` bounds `J`.

## 2. Zariski–Lipman: complete ideals, weighted clusters, excesses

This section is classical. It is quoted here in the exact form used, with the
statements checked against their sources, because the repository has not used
this machinery before: the terms *complete ideal*, *weighted cluster* and
*infinitely near point* do not occur anywhere in `problems/E-klein-cubic/` prose
outside this packet.

### 2.1 The factorization theorem — quoted correctly, with one repair

**Theorem (Zariski; Lipman).** In a two-dimensional regular local ring `R`:
(i) the product of two integrally closed (= complete) ideals is complete;
(ii) every complete `m`-primary ideal factors **uniquely** as a product of
simple complete ideals.

Zariski proved this for `R` with algebraically closed residue field of
characteristic zero (Zariski–Samuel, *Commutative Algebra II*, Appendix 5);
**Lipman**, *Rational singularities, with applications to algebraic surfaces and
unique factorization*, Publ. Math. IHÉS **36** (1969), 195–279, removes the
hypothesis on the residue field, which is what we need since `kappa(eta_S)` is
not algebraically closed.

> **Repair (the source states the theorem for `m`-primary ideals and then
> applies it to `I`, which need not be `m`-primary).** `I = (a, fJ)` has height
> one exactly when `a` and `fJ` share a factor — e.g. `J = 0`, i.e. `C`
> proportional to `B` identically, gives `I = (a)`. The standard fix is
> standard: in a 2-dimensional regular local ring (a UFD) every ideal factors as
> `I = (g) · I'` with `g = gcd(I)` and `ht(I') >= 2`, and `Ibar = (g) · I'bar`
> because `(g)` is invertible. So the classification below applies verbatim to
> the `m`-primary part `I'`, and the divisorial part `(g)` is exactly the local
> equation of the **divisorial common factor** `D_X` that the whole packet is
> about. We state everything for `I'` and suppress the prime.

### 2.2 Clusters and excesses

Let `pi : Z → Spec R` be the normalized blowup of `I`, so `I O_Z = Ibar O_Z =
O_Z(-D)` is invertible. `Z` is obtained by a finite sequence of point blowups;
the points blown up form the **cluster** `B` of proper and infinitely near base
points `p`. Writing `E_p^*` for total transforms (`E_p^* · E_q^* = -delta_{pq}`)
and `E_p` for strict transforms, `D = sum_p m_p E_p^*` defines the **point
basis** `(m_p)`, and the **excess** at `p` is

```
rho_p  =  m_p  -  sum_{q proximate to p} m_q  >=  0.                    (5)
```

Then

```
D . E_p  =  -rho_p,                                                     (6)
Ibar     =  prod_p  P_p^{rho_p}   (Zariski factorization).              (7)
```

*Check of (6).* `E_p = E_p^* - sum_{q ≻ p} E_q^*`, so
`D · E_p = -m_p + sum_{q ≻ p} m_q = -rho_p`. This is the standard convention
(Casas-Alvero, *Singularities of Plane Curves*, LMS Lect. Notes 276, §4.5 and
Thm 8.4.6); the source quotes both (6) and (7) correctly.

### 2.3 Excess = degree of the exceptional map — the derivation checked

**Proposition 2.3.** The five coordinates of `A` generate `O_Z(-D)`, hence
define a morphism `q_Z : Z → X` with `q_Z^* O_X(1) = O_Z(-D)`, and for every
`p` in the cluster

```
(q_Z|_{E_p})^* O_X(1)  =  O_{E_p}(rho_p),   i.e.   deg(q_Z|_{E_p}) = rho_p.  (8)
```

Consequently `rho_p = 0` iff `E_p` is contracted by `q_Z` (target-constant), and
`rho_p > 0` iff `E_p` is **dicritical** (a Rees component of `I`).      (9)

*Proof.* On the normalized blowup `I O_Z` is invertible and equal to
`Ibar O_Z = O_Z(-D)`, so dividing the five coordinates by a local generator of
`O_Z(-D)` gives five sections generating `O_Z(-D)`, i.e. a morphism to `P^4`
with `q_Z^*O(1) = O_Z(-D)`; it lands in `X` because `F(A) = 0` identically.
Restricting to `E_p ≅ P^1_{kappa(p)}` and taking degrees,
`deg (O_Z(-D)|_{E_p}) = -D·E_p = rho_p` by (6). ∎

The derivation of (8) from `Ibar O_Z = O_Z(-D)` is exactly as the source states
it. Exits `SLICE-COMPLETE-IDEAL-CLUSTER-CLASSIFICATION-PROVED`,
`SLICE-EXCESS-EQUALS-RATIONAL-CURVE-DEGREE-PROVED`.

### 2.4 The decoration — with the residue-field caveat the source omits

The exceptional fibre of `Z → Spec R` is a connected tree of `P^1`'s, so of
arithmetic genus zero; the strict transform of `f = 0` meets it in one point,
which `q_Z` sends to the primitive restricted value `[B(eta_S)] ∈ X`. Deleting
the `rho_p = 0` components and stabilizing gives a **pointed genus-zero stable
map to `X`**.

> **Caveat (omitted by the source).** `kappa(eta_S)` is not algebraically
> closed. Blowing up a closed point `p` of a regular two-dimensional scheme
> gives `E_p = P(m_p/m_p^2) ≅ P^1_{kappa(p)}` — still a `P^1`, but over the
> residue field of `p`, which may be a proper extension. So the decoration is a
> pointed genus-zero stable map **over `kappa(p)`**, the tree carries a Galois
> action, and components may be conjugate rather than individually defined over
> the base. The source does list "Galois action on the cluster" among the
> classifying data, so this is a gap in its statement of the conclusion, not in
> its data. Nothing downstream in this packet uses the split form.

### 2.5 What "complete classification" does and does not mean

**Proposition 2.5.** Up to multiplication by a unit of `R`, giving a slice tuple
`A` with `F(A) = 0` is the same as giving

* a complete ideal `Ibar ⊂ R` — equivalently, by (7), a weighted cluster with
  its proximity relations, point basis and Galois action; together with
* a morphism `q_Z : Z → X` from the corresponding normalized blowup with
  `q_Z^* O_X(1) ≅ O_Z(-D)` and the five pulled-back coordinates generating,
  i.e. a pointed genus-zero stable map to `X` whose component degrees are the
  excesses `rho_p`.

*Proof.* Forward: sections 2.2–2.4. Backward: the five sections of `O_Z(-D)`
push forward to five elements of `R` generating an ideal with the given integral
closure, and `F` of the tuple vanishes because the image lies in `X`. ∎

> **Repair.** The source writes "complete classification: normalized slice tuple
> = complete-ideal weighted cluster + compatible pointed rational stable map to
> `X`" without saying up to what. Proposition 2.5 is the statement with the
> equivalence pinned down. It is a *dictionary*, not a finiteness theorem: the
> cluster size is unbounded (section 5) and the target degrees are unbounded
> (section 4).

## 3. Universality: every pointed rational curve occurs

This is the sharpest content of the round, and it is correct.

**Theorem 3.1 (universality).** Let `K` be a field of characteristic zero and
`gamma : P^1_K → X_K` any morphism of degree `e >= 1`, given by a base-point-free
`5`-tuple `P(s,t)` of binary forms of degree `e` with `F(P) = 0`. Put

```
R = K[[s,t]],   f = s,   H = t^e,   b = P(0,1),   B = b,   C = (P - t^e b)/s.
```

Then `A := H B + f C = P`, `F(A) = 0`, and the four landing identities (10) hold
in `R` with

```
R_0 = 0,     R_1 = 3 Phi(b,b,C)/s,     R_3 = F(C)/t^e,
```

all three divisions being exact. The slice ideal has integral closure
`Ibar = (s,t)^e`; the cluster is the single point `m` with `m_m = rho_m = e`; and
the exceptional map `q_Z|_E : E ≅ P^1 → X` is **exactly `gamma`**.

*Proof.* `P` is homogeneous of degree `e`, so `P(0,t) = t^e P(0,1) = t^e b`, and
`b ≠ 0` because `P` is base-point free; hence `s | (P - t^e b)` and `C` is well
defined, with `HB + fC = t^e b + (P - t^e b) = P`.

The identities. Since `[b] = gamma([0:1]) ∈ X(K)`, `F(b) = 0`, so **(I0) holds
with `R_0 = 0`** — the `R_0` of a landing slice is forced to vanish in this
construction. Expanding the cubic,

```
0 = F(P) = t^{3e}F(b) + 3t^{2e}s Phi(b,b,C) + 3t^e s^2 Phi(b,C,C) + s^3 F(C)
```

(verified symbolically for `e = 1,2,3,4` with free `b` and `C`, `S2a`), and
`F(b) = 0`, so dividing by `s`:

```
0 = 3 t^{2e} Phi(b,b,C) + 3 t^e s Phi(b,C,C) + s^2 F(C).                (*)
```

*mod `s`*: `3 t^{2e} Phi(b,b,C)|_{s=0} = 0` and `t^{2e} ≠ 0` in the domain `R`,
so `s | 3Phi(b,b,C)`; set `R_1 = 3Phi(b,b,C)/s`, which is **(I1)** with
`R_0 = 0`. Substituting `3Phi(b,b,C) = s R_1` into `(*)` and dividing by `s`:

```
0 = t^{2e} R_1 + 3 t^e Phi(b,C,C) + s F(C).                            (**)
```

*mod `t^e`*: `t^e | s F(C)` and `gcd(s, t^e) = 1` in the UFD `K[[s,t]]`, so
`t^e | F(C)`; set `R_3 = F(C)/t^e`, which is **(I3)**. Substituting into `(**)`
and dividing by `t^e` gives `t^e R_1 + 3Phi(b,C,C) + s R_3 = 0`, which is
**(I2)**. Both divisibility-to-identity steps are verified as exact symbolic
manipulations (`S2b`, `S2c`).

The ideal. `Ibar`: the `P_i` are forms of degree `e`, so `I ⊆ m^e` and
`Ibar ⊆ m^e` (powers of `m` are integrally closed). Conversely `P` is
base-point free, so the `P_i` have no common zero on `P^1` and `I O_{Bl_m}` is
invertible equal to `O(-eE)`; hence `Ibar = Gamma(Bl_m, O(-eE)) ∩ R = m^e`. The
cluster is the single point `m` with `m_m = e`, no proximate points, so
`rho_m = e`, matching (8): `deg(q_Z|_E) = e = deg(gamma)`.

The map. On the chart `t = s w` the tuple is `P(s, sw) = s^e P(1,w)`, so after
dividing by the local equation `s^e` of `E` the restriction to `E` is
`w |--> [P(1,w)] = gamma(w)`. Verified for every instance in `S4`.

The marked point. The strict transform of `f = s = 0` meets `E` at `w = ∞`,
i.e. at `[s:t] = [0:1]`, whose image is `[b] = [B(eta_S)]`. ∎

**Corollary 3.2 (the box of the round).** *Every* pointed rational curve on `X`,
of *every* degree, occurs as a normalized two-dimensional slice satisfying the
four landing identities. The identities do not distinguish lines from conics,
from higher-degree curves, or from multiple covers.

**Verified instances** (`verify_slice_universality.py`, block `S3/S4`, all exact

|---|---|---|---|---|
| coordinate line `{x1=x3=x4=0}` | 1 | `(0,0,1,0,0)` | `0` | `0` |
| the smooth conic of `COUNTERMODEL_CONIC_SLICE.md` | 2 | `(1,-2,1,-2,0)` | `8` | `-8s` |
| plane rational cubic (below) | 3 | `(0,-1,0,-3,0)` | `t` | `4s^3-4s^2t-2t^3` |

The script checks `F(P) = 0`, `gcd = 1`, that the image spans a plane (rank 3 in

## 5. Higher normal-jet depth is unbounded at fixed target degree

**Theorem 5.1.** For every `N >= 1` the tuple

```
A_N = (s^N, 0, t, 0, 0)                                                 (12)
```

satisfies `F(A_N) = 0` and has slice ideal `I_N = (t, s^N)`, which is complete.
Its cluster is a **free chain** `p_0 < p_1 < ... < p_{N-1}` of `N` points with
point basis `m_{p_i} = 1` for all `i` and excesses

```
rho_{p_i} = 0  (i < N-1),      rho_{p_{N-1}} = 1.                       (13)
```

The first `N-1` exceptional components are target-constant; the last maps with
degree `1` onto the coordinate line `{x_1=x_3=x_4=0} ⊂ X`. The landing
identities hold with `f = s`, `H = t`, `B = (0,0,1,0,0)`, `C = (s^{N-1},0,0,0,0)`
and `R_0 = R_1 = R_3 = 0`.

*Proof.* `F(A_N) = 0` because every Klein monomial `x_i^2 x_{i+1}` meets a zero
coordinate (`S5a`). `I_N = (t, s^N)` is a monomial ideal whose Newton polyhedron
is `{(a,b) : a/N + b >= 1}`; every lattice point of it already lies in
`(t, s^N)` (`b >= 1` puts it in `(t)`; `b = 0` forces `a >= N`), so `I_N` is
integrally closed (`S5b`). Quadratic transforms: `ord(I_N) = 1`, so `m_{p_0} =
1`; in the chart `t = s t'` the ideal is `s·(t', s^{N-1})`, and in the chart
`s = t s'` it is `t·(1, ...) = (t)`, already principal — so there is exactly one
base point at each stage and the chain is free, with `(t^{(k)}, s^{N-k})` at
`p_k` (`S5c`). All `m_{p_i} = 1`; `p_{i+1}` is proximate to `p_i` only; hence
`rho_{p_i} = 1 - 1 = 0` for `i < N-1` and `rho_{p_{N-1}} = 1 - 0 = 1` (`S5d`).
For the last component, substituting `t = s^{N-1}·(s W)` gives
`A_N = s^N·(1,0,W,0,0)`, i.e. after dividing by the local equation the map is
`W |--> [1:0:W:0:0]`, degree `1` onto the coordinate line (`S5e`) — matching (8),
`deg = rho = 1`. The identities: `A_N = t·(0,0,1,0,0) + s·(s^{N-1},0,0,0,0)`,
and `F(B) = 0`, `Phi(B,B,C) = 0`, `Phi(B,C,C) = 0`, `F(C) = 0`, so all four hold
with all `R_i = 0` (`S5f`, `S5g`). ∎

Verified for `N = 1,...,12`. Exit `HIGHER-NORMAL-JET-DEPTH-UNBOUNDED`.

## 6. Consequence: `(10)` constrains nothing about curve type

pointed `(gamma, [b])` with `gamma : P^1 → X` occurs, with `R_0 = 0` and

*Proof.* Theorem 3.1 and Theorem 5.1. ∎
