## 1. The complex

```
0 --> O(5-2d) --P_T--> T_{P^4} --dT--> E_T --> 0,
H_0 = ker(dT)/O(5-2d)·P_T,     H_1 = coker(dT),
```

with `E_T` the rank-`3` pullback-of-`T_X` sheaf. Ranks `1, 4, 3` give
`rank H_0 = rank H_1 = 0`, so both are torsion, and in `K`-theory

```
[H_1] - [H_0] = [E_T] - [T_{P^4}] + [O(5-2d)].                       (44)
```

**`ch_1` cancels.** `c_1(T_{P^4}) = 5H`, `c_1(E_T) = T^*(c_1 T_X) = 2dH` since
`c_1(T_X) = -K_X = 2H_X` and `T^*H_X = dH`. Then

```
2d - 5 + (5 - 2d) = 0,   so   ch_1(H_1) = ch_1(H_0).                 (45)
```

Verified identically in `d` by the script. So the divisorial contributions of
the two homology sheaves have equal length. Section 2 says *why*, locally.

## 2. The Smith form at a nonbase critical divisor

Let `D` be a divisor along which `dT` drops rank, with `D` **not** contained in
the base locus. Let `R = O_{P^4,D}` be the DVR at its generic point, `pi` a
uniformizer, `k(D)` the residue field.

Localised at `D`, `dT : R^4 -> R^3` has generic rank `3` (dominance), so its
Smith normal form is

```
diag(pi^{alpha_1}, pi^{alpha_2}, pi^{alpha_3} | 0),
0 <= alpha_1 <= alpha_2 <= alpha_3,   r := alpha_1+alpha_2+alpha_3.   (46)
```

> **Proposition 2.1 (the source's (47)).**
> ```
> ord_D(a_T) = r,   (H_0)_D ≅ R/(pi^r),
> (H_1)_D ≅ R/(pi^{alpha_1}) ⊕ R/(pi^{alpha_2}) ⊕ R/(pi^{alpha_3}).
> ```

*Proof.* In Smith bases the cokernel is visibly
`⊕_i R/(pi^{alpha_i})`, giving `(H_1)_D`. The kernel of the Smith matrix is
free of rank `1`, generated by the fourth basis vector `v_4`. The kernel of a
rank-`3` map `R^4 -> R^3` is also generated, over `Frac R`, by the vector of
signed maximal minors (Cramer); in Smith bases that vector is
`pi^{alpha_1+alpha_2+alpha_3} v_4`. So the minor vector has content exactly
`pi^r` relative to the saturated kernel generator `v_4`.

It remains to identify the minor vector with `P_T` up to a unit at `D`. By
`BASE_GRADIENT_PACKAGE.md` Lemma 2.1, `I_4(J_T) = I_P I_Q`; by Corollary 1.2
there, `sqrt(I_Q) = sqrt(I_T)`, so at a **nonbase** `D` the ideal `I_Q`
localises to the unit ideal. Hence `I_4(J_T)_D = (a_T)_D`. On the other hand,
passing from the ambient `5x5` `J_T` to the `4 -> 3` map `dT` costs exactly the
two trivial directions: the Euler relation `J_T x = d·T(x)` shows the radial
direction maps to `T(x)`, which is a unit vector at `D` because `D` is not in
the base locus, and the left kernel is spanned by `Q_T`, again a unit vector
there. So `J_T` has Smith invariants `(0, alpha_1, alpha_2, alpha_3, -)` at `D`
and `I_4(J_T)_D = (pi^{r})`. Therefore `ord_D(a_T) = r`, and
`(H_0)_D = ker/(a_T·saturated generator) ≅ R/(pi^r)`. ∎

> **Corollary 2.2.** Every divisorial defect is classified by a **partition of
> `r` into three parts** `r = alpha_1 + alpha_2 + alpha_3`, and
> `length (H_0)_D = length (H_1)_D = r`. This is the local explanation of (45):
> the divisorial contributions cancel before `ch_2`.

The partition is a genuine extra invariant, not determined by `r`: `(0,0,r)`
(one deep degeneration) and `(1,1,r-2)` (three shallow ones) have the same
`a_T`-order but different `H_1`.

## 3. The codimension-two balance

Computing `ch_2` of (44) with `ch(T_{P^4}) = 5e^H - 1`,
`ch_2(T_X) = -2H_X^2` (from `0 -> T_X -> T_{P^4}|_X -> O_X(3) -> 0`) and
`T^*(H_X^2) = d^2 H^2`:

```
ch_2(E_T) - ch_2(T_{P^4}) + ch_2(O(5-2d))
   = -2d^2 - 5/2 + (5-2d)^2/2  =  10 - 10d,
```

verified identically in `d` by the script. Hence

```
[H_1]_2 - [H_0]_2 = [Q_T]_2 - 10(d-1)H^2,                            (48)
```

where `[Q_T]_2` is the codimension-two correction by which `E_T` differs from an
honest pullback — i.e. the excess/base-locus term. **The source does not define
`[Q_T]_2`.** What is exact here is the coefficient `-10(d-1)`; the rest is a
bookkeeping name. Writing `[Q_T]_2 = b_T H^2`,

```
deg[H_0]_2 - deg[H_1]_2 = 10(d-1) - b_T.                             (49)
```

At `d = 35` the threshold is `10·34 = 340`:

* `b_T = 0` forces a codimension-two kernel/saturation defect of degree `>= 340`;
* `H_0 = 0` forces `b_T >= 340`;
* otherwise the two effective defect cycles differ by exactly `340 - b_T`.

**This is a numerical constraint, not an effectivity contradiction**, exactly as
the source says — and exactly as `DEFECT_IDENTITY.md` already found for the
`ch_1`-level identity (`DEFECT-IDENTITY-IMPOSES-NO-EFFECTIVITY-CONSTRAINT`).
Effectivity of all three terms requires `a_T = 1`; by
`BASE_GRADIENT_PACKAGE.md` §5 that is one of the two allowed regimes
(`e = 0` or `e >= 5`), so the hypothesis is not vacuous, but neither is it
forced.
