FIX-H0  PAYLOAD -- the two global theorems, with the machine certificates
=========================================================================

SETTING.  G = PSL(2,11), W the 5-dim Weil representation, X = V(F) subset
P(W) the Klein cubic.  f : P(W) --> X is G-equivariant and dominant.  G is
perfect, so the twisting character is trivial and f is given by a tuple T of
W-valued forms of degree d with gcd 1 and

        T(g v) = rho(g) T(v)   (all g in G),        F(T) = 0 .

For an involution sigma:  W = W+ (+) W-, dim 3 and 2;  P_sigma = P(W+)
(a plane in the SOURCE),  L_sigma = P(W-) subset X,  E_sigma = X cap P_sigma.
Write v = w + y  (w in W+, y in W-)  and  T = T+ + T-  accordingly.
ord_{P_sigma} = the (y)-adic order.


THEOREM H0-1  (plus-plane parity).
        ord_{P_sigma}(T-)  <  ord_{P_sigma}(T+)   for every involution sigma;
        hence  m := ord_{P_sigma}(T)  is ODD, and in particular m >= 1
        (every one of the 55 plus-planes is in the base locus of f).

PROOF.

(i)  sigma acts as +1 on W+ and -1 on W-               [certificate A1]
     => T+(w,-y) = T+(w,y)  and  T-(w,-y) = -T-(w,y),
     so T+ is EVEN and T- is ODD in y;  a := ord T+ is even, b := ord T- is
     odd, and a != b.                                   [certificate B]

(ii) T- == 0 would put the image of f inside X cap P(W+) = E_sigma, and
     T+ == 0 would put it inside L_sigma; both contradict dominance.
     So a, b < infinity.

(iii) Suppose a < b.  Blow up the smooth, C_G(sigma)-stable, codimension-2
     centre P_sigma.  Since N_{P_sigma/P^4} = O(1) (x) W-,

          D_sigma = P(N) = P_sigma x P(W-)  ~  P^2 x P^1  ,

     which is RATIONAL.  The induced rational map on D_sigma is given by the
     y-degree-a leading form, which is (T+_a , 0) because T- starts only at
     y-degree b > a.  So

          phi : D_sigma --> P(W+),   phi = [ T+_a(w;y) ] ,

     nonzero on a dense open set; its image lies in X (the graph closure of f
     lies in P^4 x X), hence in X cap P(W+) = E_sigma.

     E_sigma is a SMOOTH plane cubic                    [certificate A6]
     => genus 1 => no rational curves => phi is CONSTANT (Note I, Lem 4.2),
     say with value e in E_sigma.

     D_sigma is C_G(sigma)-stable and phi is C_G(sigma)-equivariant, so e is a
     C_G(sigma)-fixed point of P(W+).  But P(W+) has EXACTLY ONE such point,
     the D12-point z_sigma = [triv], and F(z_sigma) != 0, i.e. z_sigma is OFF
     X.                                                 [certificate A4]
     Contradiction.

(iv) Hence b < a and m = min(a,b) = b is odd.  Taking a = 0 in (iii) gives
     m >= 1.                                                            QED


THEOREM H0-2  (the point option is impossible).
        With m odd, the induced map on D_sigma is
            psi = [ 0 : T-_m(w;y) ] : D_sigma --> P(W-) = L_sigma ,
        and psi is NON-CONSTANT, hence DOMINANT onto L_sigma.

PROOF.  T-_m != 0, so psi is defined on a dense open set and is
C_G(sigma)-equivariant.  A constant value would be a C_G(sigma)-fixed point
of P(W-); there is NONE -- W- is an irreducible C_G(sigma)-module (Burnside:
the generated algebra is all of M_2, dimension 4; equivalently every linear
character of C_G(sigma) has multiplicity 0 in W-).      [certificate A5]
So psi is non-constant, and its image is an irreducible curve inside the
curve L_sigma, i.e. all of L_sigma.                                     QED

REMARK (why the verdict is robust to new witnesses).  ord(T+) is ALWAYS even
and ord(T-) ALWAYS odd, so  m = min  is odd  <=>  the minus half leads.
Theorem H0-1 is therefore literally the single sentence "m is odd", and any
stalk component -- including ones not yet discovered -- is excluded exactly
when its m is even.  E.g. FIX-N2C's Theorem N2C-1' (all three lam-eigenblocks
at (1,7) populated, 27 points, each with plane orders (1,1,1)) adds 18 further
m=1 points; all have m odd, so all survive.
